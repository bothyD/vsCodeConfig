# 🛠️ VS Code Python & Pytest Config

Этот репозиторий содержит готовую конфигурацию среды для **VS Code**. Настройки позволяют писать код по стандартам PEP8, автоматически подхватывают виртуальные окружения (`venv`/`.venv`) и дают возможность полноценно управлять редактором, тестами и дебаггером **без использования мыши**.

---

## 🌍 Глобальная настройка на все проекты (через Ctrl+Shift+P)

Чтобы эти настройки и горячие клавиши применялись автоматически для всех текущих и будущих проектов, их нужно добавить в глобальный профиль пользователя VS Code:

### 1. Установка настроек редактора (`settings.json`)
1. Нажмите комбинацию **`Ctrl + Shift + P`** (или `Cmd + Shift + P` на Mac).
2. Наберите и выберите пункт: **`Preferences: Open User Settings (JSON)`** *(важно: выберите вариант со словом "JSON")*.
3. Полностью замените содержимое открывшегося файла кодом из вашего `settings.json`.

### 2. Установка горячих клавиш (`keybindings.json`)
1. Снова нажмите комбинацию **`Ctrl + Shift + P`**.
2. Наберите и выберите пункт: **`Preferences: Open Keyboard Shortcuts (JSON)`**.
3. Полностью замените содержимое открывшегося файла (внутри квадратных скобок `[ ]`) кодом из вашего `keybindings.json`.

## ⌨️ Шпаргалка по горячим клавишам (No-Mouse Flow)

Все кастомные хоткеи настроены на мгновенную навигацию и управление тестированием.

### 🧪 Запуск и отладка Pytest
Все команды запуска тестов объединены под общим аккордом-мнемоникой **`Ctrl + T`** (от слова **T**est):
* `Ctrl + T` ➡️ `Ctrl + T` — **Запустить строго один тест**, на котором сейчас стоит курсор.
* `Ctrl + T` ➡️ `Ctrl + A` — **Запустить тесты** для всего текущего файла.
* `Ctrl + T` ➡️ `Ctrl + D` — **Запустить дебаггер** для теста под курсором.
* `Ctrl + T` ➡️ `Ctrl + F` — **Запустить дебаггер** для всего текущего файла.
* `Ctrl + T` ➡️ `Ctrl + R` — **Быстрый перезапуск** последнего прогнанного теста (работает из любого файла).

### 🪲 Управление дебаггером в процессе отладки
* **`F9`** — Поставить / снять красную точку останова (**Breakpoint**) на текущей строке.
* **`F5`** — Продолжить выполнение до следующей точки останова (**Continue**).
* **`F10`** — Сделать шаг вперед без захода внутрь функций (**Step Over**).
* **`F11`** — Шагнуть внутрь вызываемого метода/функции (**Step Into**).
* **`Shift + F11`** — Выйти из текущей функции наружу (**Step Out**).
* **`Shift + F5`** — Полностью остановить отладку (**Stop**).

### 🖥️ Переключение панелей и вкладок
* **`Ctrl + [`** / **`Ctrl + ]`** — Листать вкладки нижней панели влево/вправо (**Problems ↔ Output ↔ Test Results ↔ Terminal**).
* **`Ctrl + Alt + [`** / **`Ctrl + Alt + ]`** — Быстро переключаться между **открытыми файлами** (вкладками редактора) влево и вправо.
* **`Ctrl + Space`** — Показать / скрыть нижнюю панель целиком.
* **`Ctrl + \``** (тильда) — Мгновенно прыгнуть клавиатурным фокусом внутрь Терминала.
* **`Ctrl + Left`** / **`Ctrl + Right`** — Переключение между сплитами (соседними окнами) терминалов.

### 📁 Навигация по проекту
* **`Ctrl + Shift + E`** — Переместить фокус на дерево файлов слева (Проводник). После этого можно ходить по папкам стрелочками клавиатуры, открывать файлы на `Enter` и разворачивать папки на `Space`.
* **`Ctrl + B`** — Показать / скрыть левую боковую панель (сайдбар), чтобы освободить экран для кода.
* **`Escape`** — Мгновенно вернуть фокус (каретку) обратно в редактор кода из терминала или боковой панели.
* **`Ctrl + P`** — Быстрый поиск и открытие любого файла в проекте по его названию.

### 🔤 Форматирование текста
* **`Ctrl + L`** — Перевести выделенный текст в **нижний регистр** (lowercase).
* **`Ctrl + U`** — Перевести выделенный текст в **ВЕРХНИЙ РЕГИСТР** (uppercase).

## 🚀 Основные фишки этой сборки

1. **Авто-Venv:** VS Code автоматически ищет папки окружения `.venv` или `venv` в корне. Больше не нужно выбирать интерпретатор через `Select Interpreter`.
2. **Чистые импорты:** Корень проекта и папка `uc_modules` жестко зафиксированы в путях. Линтер Pylance больше не ругается на локальные импорты.
3. **PEP8 из коробки:** Настроена невидимая обрезка лишних пробелов на концах строк и гарантированное добавление одной пустой строки в самый конец файла при сохранении (`Ctrl + S`).
